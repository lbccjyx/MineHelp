# HookAlerter —— 黄金矿工「鼠标指哪 钩子钩哪」

纯外部工具：**不修改游戏文件、不注入进程、不读游戏内存**，只靠屏幕像素工作。

---

## 它做什么

```
1. 算出"转轴 → 鼠标"这条线的角度
2. 沿这条线打射线，看线上有没有值得勾的东西
3. 钩子摆动到接近这条线时 → 自动替你按下方向下键
```

| 线上是什么 | 结果 |
|---|---|
| 金块 / 钱袋 / 钻石 | 出钩 |
| 石头 | 不出钩 |
| 空 | 不出钩 |

**不看物体大小** —— 碎金也算。值不值得拿是你的判断。

---

## 运行

1. 先启动游戏，进入关卡，让钩子正常摆动
2. 双击 `HookAlerter.exe`
3. 自动找窗口 → 自动标定 → 开始工作
4. 关闭控制台窗口即退出

> **游戏失焦会整个冻结**，所以工具做成不抢焦点的窗口。
> 点面板改参数时游戏会暂停一下，改完点回游戏即可。

## 面板

```
[ 提示：开启中 ]  [ 画面文字：关 ]  [ 自动出钩：开 ]   [ 收起 ]
提前量        回钩静默        [ 应用 ]
[ 0 ]        [ 500 ]
[ 状态栏：钩子角度 / 鼠标角度 / 线上是什么 / 差值 ]
[ 重新标定 (F8) ]  [ 保存诊断图 (F9) ]  [ 录制诊断 8 秒 ]
```

| 控件 | 说明 |
|---|---|
| **提示：开启/暂停** | 总开关 |
| **画面文字** | 在画面底部显示实时状态 |
| **自动出钩** | 开 = 程序替你按键；关 = 只提示 |
| **提前量** | 额外提前量，默认 0（程序已自学习过冲补偿） |
| **回钩静默** | 钩子刚收回来这段时间摆动混乱，不判断。默认 500ms |
| **收起** | 缩成小球 |

参数改完**按回车或点"应用"**生效，自动存 ini。填非法值输入框会**变红**提示。

## 核心原理

### 判定：钩子进入"目标物体自身的角度区间"

钩子沿**当前摆动角度**直线飞出。所以"指哪钩哪"= 让摆动角度等于鼠标方向。

判定用的是**目标物体占的角度区间**（由射线命中后连通区域反推），
而不是一条无限细的线 —— 物体有宽度，要求钩子咬住中心线等于人为把靶子缩小。

### 出钩时机：在"最近格点"显示期的中段按下

游戏约 18fps，钩子位置**一格一格跳**。关键在于按键落在格子显示期的哪一点：

```
格子 A 显示中 ─────────────────────────┐
                    ↑ 在这里按（中段）
前后各留半帧余量 → 游戏无论快慢半帧，看到的都是格子 A
```

开火窗口 = `max(5°, 格间距 × 0.75)`。**5° 下限很重要**：钩子在摆动两端会减速、格间距缩小，
窗口若跟着缩，最需要开火时反而最窄，就会"到过 3° 却不开火"。

### 过冲自学习

实测发现钩子**总是朝摆动方向飞过头 1~8°**。程序把每次的过冲量记下来取中位数，
下次提前这么多开火 —— 自动校准，游戏状态变了也会跟着变。

### 转轴是实测常数

从绳子像素反解：`转轴y = 泥土线 − 画面高 × 4.9%`，x = 场地中心。
两次独立测量分别得到 (966,118) 和 (967,118) 吻合。

**转轴错了会导致所有角度整体偏移，且目标越远偏得越多** —— 这是最致命的错误来源。

### 跟踪器必须锁在弧线上

钩子始终**骑在离转轴固定半径的弧线**上。这是识别它的最强约束：

- 搜索框内只接受**在弧线上 + 转轴下方 + 摆动弧内**的灰色变化像素
- 静态半径 `RestR` **限幅在标定值 ±35%**

> 早期版本让 `RestR` 随跟踪长度自由漂移，形成**自我强化陷阱**：
> 跟错 → 长度变短 → 半径被拉小 → 半径检查更宽松 → 继续跟错。
> 一锁错就再也出不来，表现是"有时很准、有时差 20°"。
> 更糟的是，离转轴很近的假目标（如绞盘）**挪动 12 像素角度就变 28°**，
> 输出的全是噪声。

## 排查

打开 `画面文字`，或看 `hookalerter.log`：

```
[fire]   aim=  15.95  hook=  16.56  diff= 0.61deg  obj=  9.8.. 22.3  centre= 15.6  r=39  GOLD
[flight] aim=  15.95  fired=  16.56  flew= 13.30  over= -3.26deg  lead=  3.26deg  obj= 9.8..22.3
```

| 字段 | 含义 |
|---|---|
| `aim` | 鼠标线角度 |
| `hook` / `fired` | 开火瞬间跟踪到的钩子角度 |
| `flew` | **实际飞出去的方向**（射出去后量绳子） |
| `over` | 飞过头的量（`flew − fired`） |
| `obj` | **目标物体自身占的角度区间** |

每次出钩还会写入**前后 100+25 帧的逐帧决策追踪**：

```
---- decision trace around a shot ----
[trace] ang= -4.72 aim= -5.59 d= 0.87 half= 4.98 obj= -13.6..2.1 inObj=1 near=1 ... *** FIRE ***
```

`hx,hy` 是跟踪到的钩子坐标，`piv` 是转轴 —— **两者距离应稳定在 45~55 像素**。
如果挤在一个小方块里，说明跟踪器锁错了目标。

---

## 已知限制

- **石头挡在金块前面时不出钩** —— 故意的，射线报告石头是真话
- **任何"成块的非灰色物体"都会被当成金块**，包括 TNT、骨头
- 游戏失焦时冻结，无法后台工作
- 改变窗口大小后按 `F8` 重新标定
